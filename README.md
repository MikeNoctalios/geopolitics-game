# Geopolitics AI — «стол»

Пошаговая геополитическая игра с ИИ-гейммастером. Вы правите державой, пишете указы на печатной машинке,
переписываетесь с правителями, созываете саммиты и управляете армией печатями. Мир отвечает ходом.

## Запуск
1. Нужен **Python 3.9+** (на Windows при установке отметьте «Add Python to PATH»).
2. Дважды щёлкните **`run.bat`**. При первом запуске он сам доустановит нужное (`openai`). Откроется браузер.
   Нажмите **F11** для полного экрана. Чтобы остановить игру, закройте окно консоли.
3. **Ярлык на рабочий стол:** один раз запустите `create_shortcut.bat`.
4. Подключение к ИИ: телефон в левом нижнем углу → **Настройки** → ключ API, адрес (для не-OpenAI провайдеров) и модель →
   «Проверить связь». Без ключа игру можно открыть и смотреть, но ход обработать нельзя.

В папке `scenarios/` лежит демо-сценарий «Эпоха дредноутов (1910)». Свои сценарии (`.json`) кладите туда же.

## Где что хранится
| Что | Где |
|---|---|
| Сохранения (3 ячейки) | `saves/` |
| Ключ API и модель | `config.json` (не отправляйте его никому) |
| Цвета, шрифты, размеры | `ui_prefs.json` (меняются на телефоне → «Оформление») |
| Ваши шрифты | `fonts/` (загружаются там же) |
| Журнал сбоев API | `logs/api_errors.log` |

## Если что-то не так
- **Ошибки 500 от провайдера:** смотрите `logs/api_errors.log` (время, размер запроса, через сколько секунд сбой).
  Если провайдер ругается на нагрузку, в `config.json` поставьте `"max_workers": 1`.
- **Ход не засчитался:** состояние игры при сбое не меняется; повторите «Завершить ход». «Откат» и «вперёд» — на телефоне → «Ходы».
- **Порт занят:** сервер сам возьмёт следующий свободный (адрес написан в окне консоли).

## Для разработки
`python3 tests/test_smoke.py`, `test_server.py`, `test_fresh_install.py` (нужен только Python); `test_web.py`, `test_tabs.py` —
в настоящем браузере (`pip install playwright && playwright install chromium`). Подробности и список правок — в `ИЗМЕНЕНИЯ.md`.
Шрифты в `web/fonts/` — отдельные лицензии (`web/fonts/LICENSES.txt`): четыре из них только для личного использования.
